# 🧊 Electrum-GRS Wallet

> 💎 The lightweight, secure, and lightning-fast wallet for **Groestlcoin (GRS)**

Welcome to **Electrum-GRS** — a streamlined and user-friendly wallet built on the battle-tested Electrum framework. Designed specifically for **Groestlcoin**, this wallet offers security, speed, and flexibility — without the blockchain bloat.

---

## ✨ Highlights

- ⚡ Instant setup — no full blockchain download required
- 🔒 Built-in support for cold storage & hardware wallets
- 🖥️ Cross-platform: Windows, macOS, Linux
- 🌐 Fully open-source and community-driven
